# Sri Lanka Electorate Boundaries

Spatial polygon boundaries for the 160 electorates (polling divisions)
across the 22 electoral districts of Sri Lanka.

## Usage

``` r
SLElectorate
```

## Format

An sf object with 160 rows and 5 columns:

- ElecCode:

  Electoral electorate code.

- District:

  Electoral district name.

- Electorate:

  Standardised electorate (polling division) name.

- OrigName:

  Original name in the spatial dataset.

- geometry:

  Spatial polygon geometry.

## Source

<https://github.com/nuuuwan/sl-topojson>

## Details

Electorates names have been standardised using the 2024 Sri Lankan
presidential election dataset. The original names from the spatial
source are retained.
